# C++ Beginner Programs

## About
This repository contains beginner-friendly C++ programs created while learning programming fundamentals and problem-solving.

## Problem Being Solved
The project provides simple examples to practise basic programming concepts, including loops, conditional statements, arithmetic operations, and number problems.

## Technologies Used
- C++
- Visual Studio Code
- GitHub

## Programs Included
- **FizzBuzz:** Prints numbers and replaces multiples of 3 and 5 with specified words.
- **Palindrome Number:** Checks whether a number reads the same forwards and backwards.
- **Add Two Integers:** Calculates the sum of two integers.

## How to Run
1. Install a C++ compiler.
2. Download or clone this repository.
3. Open a `.cpp` file in Visual Studio Code.
4. Compile and run the program.

Example using a terminal with a C++ compiler:

```bash
g++ FizzBuzz.cpp -o FizzBuzz
./FizzBuzz
```
